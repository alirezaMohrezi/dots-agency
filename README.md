# DOT’s — وب‌سایت · نسخه‌ی ۴

سایت چندصفحه‌ای DOT’s، فارسی و راست‌به‌چپ، با اولویت نسخه‌ی موبایل. هر صفحه یک فایل HTML مستقل است و CSS، JavaScript و تصویرها داخل خود فایل قرار دارند.

| فایل | صفحه |
|---|---|
| `index.html` | صفحه‌ی اصلی |
| `capabilities.html` | خدمات |
| `about.html` | درباره و بنیان‌گذار |
| `approach.html` | روش کار، نقشه‌ی حل مسئله |
| `work.html` | چه کرده‌ایم |
| `work-talent.html` | مطالعه‌ی موردی قهوه تلنت |
| `work-partak.html` | مطالعه‌ی موردی پارتاک استور |
| `work-coldbrew.html` | کمپین تابستان با کلدبرو |
| `work-bfyalda.html` | کمپین از بلک‌فرایدی تا یلدا |
| `work-sports.html` | پروژه‌ی تلنت × جامعه‌ی ورزشی |
| `work-connections.html` | پروژه‌ی ارتباط‌های معنادار |
| `work-captain.html` | پروژه‌ی Captain |

فونت‌ها (Estedad، DM Sans، DM Mono) از Google Fonts بارگذاری می‌شوند.

## نسخه‌ها

- **نسخه‌ی ۴** (شاخه‌ی `main`): معماری تازه (صفحه‌ی «درباره» و مسیر خدمات → نمونه‌کار → درباره → روش کار → تماس)؛ دکمه‌ها و کی‌ویژوال طبق راهنمای چیدمان (دکمه‌ی تخت ۵۲ پیکسلی با گردی ۱۰، دکمه‌ی پر فقط برای مسیر اصلی، خوانش GAP و حریم نقطه‌ی اتصال)؛ و هماهنگی با فایل لوگو: لوگو فقط امضاست، نه آیکون؛ «برگه‌ی نتیجه» به‌جای نمودار قبل/بعد؛ کی‌ویژوال دست‌ها در سر صفحه‌های خدمات، درباره و نمونه‌کار.
- **نسخه‌ی ۳** (شاخه‌ی `edition-3`): دیوار گچی با وضوح خود صفحه رسم می‌شود؛ دست‌ها با لبه‌های تمیز و ساعدهایی که نرم در دیوار محو می‌شوند؛ متن صفحه‌ی اول یک بلوک وسط‌چین؛ تصویر خلوت‌تر؛ انیمیشن ورود با رنگ‌های کرم سایت؛ و حالت ویرایش متن در هر صفحه که تغییرات را داخل خود فایل ثبت می‌کند.
- **نسخه‌ی ۲** (شاخه‌ی `edition-2`): هیروی تازه با دست ربات و دست انسان روی دیوار گچی. روی دسکتاپ متن یک ردیف کوتاه است تا تصویر بیشترِ ارتفاع را بگیرد؛ روی گوشی دکمه‌ی توقف به ردیف هدر رفته و متن روی صفحه‌های کوتاه جمع‌وجورتر می‌شود. دست‌ها با بالاترین کیفیت مرورگر رسم می‌شوند.
- **نسخه‌ی ۱** (شاخه‌ی `edition-1`): نسخه‌ی اول سایت، با هیروی شب و کهکشان.

## ویرایش متن‌ها

هر صفحه را از روی کامپیوتر باز کنید (روی سایت منتشرشده، آخر آدرس `?edit` بگذارید) و روی «ویرایش متن‌ها» بزنید. بعد از ذخیره، فایل جدید را جای فایل قبلی بگذارید. فهرست تغییرات داخل خود فایل (`#dx-edits`) ثبت می‌شود تا در ساخت‌های بعدی حفظ شود.

## سورس

پوشه‌ی `source/` قالب اصلی، اسکریپت‌های ساخت و یادداشت تحویل (`source/HANDOFF.md`) را دارد؛ برای ادامه‌ی کار در یک گفت‌وگوی تازه، اول همان یادداشت را بخوانید.
